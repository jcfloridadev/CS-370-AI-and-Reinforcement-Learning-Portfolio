# CS-370: Current and Emerging Trends in Computer Science

## Overview

This repository contains work completed for CS-370: Current and Emerging Trends in Computer Science at Southern New Hampshire University. The project demonstrates how reinforcement learning and neural networks can train an intelligent agent to navigate a maze and find treasure.

## Included Artifacts

### Project Two: Pirate Intelligent Agent

**File included:** `FloridaJustinProjectTwoMilestone.ipynb`

This Jupyter Notebook contains the Pirate Intelligent Agent project, including the code, training results, and project write-up. The provided materials included the maze environment, experience replay support, neural-network model structure, and game-play function. I implemented the Q-training algorithm using deep Q-learning, epsilon-greedy exploration, experience replay, randomized starting positions, and a periodically updated target network. The trained agent achieved a 100% recent win rate at epoch 291.

## Reflection

### What do computer scientists do, and why does it matter?

Computer scientists use programming, data, and problem-solving methods to build systems that address real needs. Their work matters because software and intelligent systems can help people and organizations solve complex problems, make informed decisions, and automate tasks.

### How do I approach a problem as a computer scientist?

I begin by understanding the goal and breaking the problem into smaller parts. I then choose an approach, implement it, and test the results. In this project, I used the agent’s training performance to evaluate its behavior and improve its ability to reach the goal.

### What are my ethical responsibilities to the end user and the organization?

Computer scientists should consider how a system affects the people and organizations that use it. AI systems need appropriate testing and monitoring. Developers should explain system limitations, protect data, and keep people accountable for consequential decisions.
